## 📚 Practice Programs

### 1. Addition of Two 64-bit Numbers Using 32-bit Registers

This program demonstrates how to add two **64-bit numbers** when the processor provides **32-bit registers**.

Since a 64-bit value cannot fit into a single 32-bit register, each number is divided into two 32-bit parts:

```text
64-bit Number
┌──────────────────────┬──────────────────────┐
│   Higher 32 Bits     │    Lower 32 Bits     │
└──────────────────────┴──────────────────────┘
```

The addition is performed in two stages:

1. Add the lower 32-bit words.
2. Add the higher 32-bit words along with the carry generated by the lower-word addition.

This exercise demonstrates the importance of **carry propagation** when performing arithmetic on values larger than the processor's register size.

---

### 2. Subtraction of Two 64-bit Numbers Using 32-bit Registers

The second exercise demonstrates subtraction of two **64-bit numbers using 32-bit registers**.

Similar to addition, the 64-bit operands are divided into two 32-bit words:

```text
64-bit Number
┌──────────────────────┬──────────────────────┐
│   Higher 32 Bits     │    Lower 32 Bits     │
└──────────────────────┴──────────────────────┘
```

The subtraction is performed by:

1. Subtracting the lower 32-bit words.
2. Propagating the borrow to the higher 32-bit subtraction.
3. Subtracting the higher words while accounting for the borrow.

This exercise provides practice with **borrow handling and multi-word arithmetic**.

## 3. 32-bit Signed Addition and Subtraction with Overflow Detection

This ARM assembly program performs **32-bit signed addition and subtraction** and checks for arithmetic overflow.

* `ADDS` performs the addition and updates the condition flags.
* `BVS` checks the **V (Overflow) flag**. If `V = 1`, signed overflow has occurred.
* `SUBS` performs the subtraction and **recalculates the V flag**, so the overflow flag does not need to be manually reset.
* If addition overflows, `R2` is set to `1`.
* If subtraction overflows, `R3` is set to `1`.
* The program then enters an infinite loop.

The **V flag is specifically used for signed overflow**, while the carry flag is used for unsigned arithmetic.
